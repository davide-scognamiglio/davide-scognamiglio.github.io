**[P1] Hero stat block = explicit absolute ban**
- Problem: .hero-meta row (6+, 12+, 8+, 500+) is the hero-metric template ban

**[P1] --ink-3 fails WCAG AA contrast at body text sizes**
- Problem: oklch(62% 0.007 80) on oklch(97.5% 0.007 80) ≈ 2.5:1 — below 4.5:1 minimum
- Where: .hero-intro, .hero-byline-sub, .pub-journal, .tl-when, .proj-sub, .hero-meta-l
- Fix: Darken --ink-3 to approximately oklch(48% 0.007 80) in light mode

**[P1] CV download is a dead link**
- Problem: assets/cv_davide_scognamiglio.pdf not present; button silently fails
- Fix: Add the PDF, or hide the button until it exists

**[P2] transition:width on scroll progress bar causes layout thrash**
- Problem: #prog{transition:width .06s linear} — confirmed by detector at line 71
- Fix: Use transform:scaleX() with transform-origin:left; update JS accordingly

**[P2] Project card numbering is banned scaffolding pattern**

- Fix: Remove number spans from MuSA card and API render function
